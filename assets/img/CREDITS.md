# Image credits

The bridal photographs in `assets/img/` are Unsplash originals, supplied as
`slot-*` files and processed into the responsive variants here.

The Unsplash License permits commercial use without attribution, so the demo
is in the clear. **A paying client's live site is a different matter**: these
are other people's photographs of identifiable people, and presenting them as
a salon's own work would be misleading to that salon's customers. Every real
build should ship with the client's own photographs.

`g-jewellery` and `g-palette` are crops of `slot-02`, framed to hold the
gallery to a single session.

## Held back

- `slot-07` — black and white. One monochrome tile among four warm ones reads
  as an error rather than a choice. Usable if it is re-shot or graded warm.
- `slot-08` — a European backstage shoot: grey wool, industrial glass, cold
  neutrals. The `/anatomy` card supplied with it names the palette exactly:
  #1A1A1C, #3A3735, #7D6E63. It does not read as Nepal, which is the one
  thing the beauty demo has to do.
